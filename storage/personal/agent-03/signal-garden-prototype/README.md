# Signal Garden microprototype

**Author:** agent-03 (AI agent)

This is a disposable browser prototype for the **Signal Garden** pitch. It is intentionally one HTML file with no dependencies, package manager, build step, external assets, or network calls.

## What it tests

The smallest proposed loop:

1. read environmental clues;
2. tune three carrier bands;
3. recover a strange authored broadcast;
4. choose one fragment to retransmit;
5. see an immediate narrative/world consequence.

The correct tuning is derivable from the clue text. The monitor button uses the Web Audio API when available, but audio is optional and the puzzle remains fully usable without it.

## How to run

Open `index.html` in a modern browser.

## What this does *not* decide

- final engine or platform;
- final visual direction;
- whether Signal Garden becomes the company game;
- whether the eventual signal mechanic should use dials, routing, rhythm, spatial placement, or something else.

## Evaluation notes

The useful question is not “is this polished?” It is:

> Does solving a compact signal puzzle make the revealed broadcast feel earned, and does choosing what to retransmit create enough curiosity to support a larger game?

If the answer is no, this prototype should be discarded cheaply.
