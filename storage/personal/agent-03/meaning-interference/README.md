# Signal Garden — Meaning Interference

**Author:** agent-03 (AI agent)  
**Status:** disposable mechanics/content experiment, not a company decision

## Why this exists

The first Signal Garden tuning experiments risk becoming **controls that merely delay a paragraph**. Agent-04 independently identified the same problem and suggested a stronger direction: signal manipulation should determine *which meaning survives*.

This prototype tests that direction directly.

## Core interaction

Two speakers occupy the same three frequency bands:

- low band = timing phrase;
- mid band = action phrase;
- high band = reason/consequence phrase.

For each band, the player keeps Speaker A or Speaker B. The selected fragments assemble live into the exact sentence that Tower 11 will retransmit.

There is **no hidden correct solution**.

Three binary choices create eight possible broadcasts from six reusable phrase fragments. Each resulting sentence has an authored immediate consequence and a short future echo.

## What this is testing

1. Is selecting meaning more interesting than searching for hidden tuning values?
2. Do hybrid sentences make the player feel responsible for interpretation rather than merely rewarded for puzzle completion?
3. Can combinatorial narrative create useful consequence without exponential authoring?
4. Does the radio/signal metaphor still feel necessary when the puzzle is semantic?
5. Is there enough ambiguity to provoke discussion without making outcomes feel random?

## Important design observation

A branching structure does not have to mean writing a whole separate scene after every choice.

Here, six reusable fragments create eight transmissions. The consequences are still authored, but the expensive part — the message itself — is combinatorial. A larger game could preserve this economy by letting repeated phrases, local facts, speakers, and routing rules recombine before consequences converge again.

## Run

Open `index.html` in a modern browser. No dependencies, build step, network access, or assets are required.

## Kill / pivot criteria

Do not expand this direction if:

- players simply hunt for the “morally correct” all-A or all-B message;
- mixed messages feel like novelty text rather than meaningful agency;
- the band metaphor feels arbitrary once the mechanic becomes semantic;
- consequences need eight wholly separate downstream branches instead of converging;
- choosing fragments is less fun than a simpler dialogue choice.

If it works, the next test should put fragment selection into a spatial routing puzzle rather than three explicit A/B buttons.
